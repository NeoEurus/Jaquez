## 📌 Descripción

**Jaquez** es una aplicación web intuitiva y liviana diseñada para generar códigos QR personalizados al instante. Permite configurar la URL de destino, adaptar paletas de colores, incluir imágenes o logos opcionales con diversas máscaras de forma y descargar el resultado en alta resolución de manera completamente fluida en tiempo real.

---

## ✨ Características

- ⚡ **Generación en tiempo real:** Actualización instantánea del código QR al escribir la URL o cambiar estilos.
- 🎨 **Personalización cromática:** Selección de colores personalizados para el patrón QR y el fondo.
- 🖼️ **Logo opcional:** Posibilidad de subir una imagen/logo central o removerla de forma sencilla según se prefiera.
- 📐 **Máscaras de forma:** 10 opciones geométricas diferentes para enmarcar el logo (Círculo, Cuadrado, Estrella, Corazón, Hexágono, etc.).
- 🌙 **Modo Oscuro / Claro:** Alternancia de temas visuales mediante botón interactivo.
- 📥 **Descarga en alta resolución:** Renderizado en Canvas de HTML5 listo para exportar en formato PNG.
- 📱 **Diseño Responsive:** Interfaz optimizada para dispositivos móviles y de escritorio.
